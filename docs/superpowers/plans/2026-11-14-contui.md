# contUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native macOS Docker client in Rust on GPUI that lists containers, images and volumes for any local Docker host, live, and navigates like Docker Desktop.

**Architecture:** One `lib` + thin `bin`. A `docker` module resolves host endpoints and owns a tokio runtime whose actor task answers list/inspect requests and forwards `/events`; the UI module holds a snapshot entity and re-renders on change. Tables are generic (`TableState` + `uniform_list`), so containers, images and volumes share one implementation. Nothing blocks the GPUI thread; nothing polls.

**Tech Stack:** Rust 1.99, `gpui 0.2.2` (Zed's GPU UI framework), `bollard` 0.21, tokio 1, async-channel 2, serde/serde_json, chrono.

**Spec:** `docs/superpowers/specs/2026-11-14-docker-gpui-client-design.md`

## Global Constraints

- Crate name `contui`, edition 2024, at the repository root (`Cargo.toml` beside `src/`). Lib + bin: `src/lib.rs` holds all modules, `src/main.rs` only calls `contui::run()`.
- `gpui = "=0.2.2"` — exact pin, never `^`, with `default-features = false, features = ["font-kit", "runtime_shaders"]`. (Ruling, Task 1: `gpui-pre` 0.3.12 on crates.io ships no platform backend — its macOS layer is an unpublished `gpui-platform` crate — so 0.2.2 is the newest self-contained official publish. `runtime_shaders` avoids the separate Metal Toolchain download that Xcode 27 requires for build-time shader compilation.)
- `bollard = "0.21"` with `default-features = false, features = ["http", "pipe", "ssl", "chrono"]`. No `ssh` feature. No `docker` CLI invocation anywhere in the program.
- Cargo may not be on `PATH`. If `cargo` is missing, use `export PATH="$HOME/.rustup/toolchains/stable-aarch64-apple-darwin/bin:$PATH"` first.
- Window 1280×820, minimum 960×600. Theme values are exactly the table in the spec (`bg #0b0d10`, `panel #12151a`, `row hover #1a1f27`, `row selected #1f2937`, `border #232a34`, `text #e6e9ef`, `text dim #8b93a1`, `accent #2f7bf6`, `running #3fb950`, `exited #6e7681`, `paused #d29922`, `error #f85149`).
- Behavior values from the spec: probe timeout 300ms, event debounce 250ms, log tail 500 lines, list re-fetch if older than 5s, reconnect backoff 1s/2s/4s…10s cap, socket probe order `~/.rd/docker.sock`, `~/.docker/run/docker.sock`, `~/.colima/default/docker.sock`, `~/.orbstack/run/docker.sock`, `/var/run/docker.sock`.
- Read-only: no start/stop/remove/pull/run endpoints are ever called.
- No polling loop. The only timer allowed is the event debounce and the reconnect backoff.
- Every network call runs on the tokio runtime. The GPUI thread never blocks on I/O.
- Errors never panic and never clear the last good snapshot.

## Review Focus

Behaviors a user would expect that no task's happy path covers. Each line names the owning task that must pin it with a test.

1. A socket that exists but refuses (permission denied) must render `Unreachable` with the reason, not hang or panic — Task 3 (`maps_ping_errors_to_host_status`).
2. A context `meta.json` that is malformed or lacks `Endpoints.docker.Host` must be skipped silently, not panic — Task 2 (fixture with truncated JSON).
3. A host answering with 10,000 containers must still scroll smoothly — Task 5 (visible-index computation over 10k rows) and `uniform_list` in Task 6.
4. Container names like the 100-character `k8s_…` leftovers must truncate with an ellipsis and never push other columns — Task 3 (`truncate`) and Task 6 (row layout with `overflow_hidden`).
5. Log bytes containing ANSI escapes, `\r`, or invalid UTF-8 must render as clean text — Task 3 (`strip_ansi`, lossy conversion).
6. The daemon restarting mid-session must flip the header to disconnected and recover without an app restart — Task 4 (stream end → status → backoff).

- [ ] **Step 3: Implement `model.rs`**

Mapping rules: `names[0]` stripped of its leading `/`, else the 12-char short id; `created` seconds → `DateTime<Utc>` and `created_label = format_ago(created, now)`; `ImageRow.repository_tag` comes from `repo_tags.first()`, falling back to `<none>`; `in_use` is passed in from the container list (`image_id` match); `VolumeRow.created_label` parses `BollardDate` (chrono-backed) and falls back to `"—"`. `strip_ansi` removes `ESC [ … m` sequences and normalises `\r\n` to `\n`; `parse_logs` uses `String::from_utf8_lossy`, splits on newlines, drops the trailing empty piece, and sets `stderr` from the `LogOutput` variant.

Formatting rules, pinned so the tests are unambiguous: `truncate` returns at most `max_chars` characters (bytes-safe, char-boundary safe), ending in `…` when it cuts. `format_bytes` divides by 1,048,576, shows one decimal below 100 (`"93.8 MB"`) and rounds above (`"436 MB"`). `format_ago` returns `"just now"` under 60s, `"{n}m ago"` under 60min, `"{n}h ago"` under 24h, `"{n}d ago"` under 30d, `"{n}mo ago"` under 365d, else `"{n}y ago"`. `format_ports` joins `"{private}"` or `"{public}→{private}"` per port with `", "`, and returns `"—"` for an empty slice.

- [ ] **Step 4: Wire it into `service.rs`**
